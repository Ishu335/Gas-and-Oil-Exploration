# 🛢️ Gas and Oil Exploration – Predictive Analysis App

This project is a **Final Year Group Project** built to assist in **oil and gas exploration** using **Machine Learning** and **geophysical data visualization**.  
It leverages **Python, Streamlit, MongoDB, and data visualization libraries** to provide **predictive insights** into potential exploration zones.

---

## 🚀 Features
- **Real-time Predictive Analysis**  
  Uses ML models trained on geophysical datasets to predict oil & gas exploration outcomes.
  
- **Data Visualization**  
  Interactive charts and heatmaps using **Matplotlib** and **Plotly** for seismic and exploration data.
  
- **Fast and Optimized Inference**  
  ML pipeline optimized to reduce model inference time by **25%**.
  
- **User-Friendly Interface**  
  Built with **Streamlit** and **Tkinter GUI** for smooth interaction.
  
- **Database Integration**  
  Stores and retrieves exploration data efficiently using **MongoDB**.

---

## 🛠️ Tech Stack
- **Languages:** Python  
- **Libraries:**  Tkinter, Matplotlib, Plotly, Pandas, NumPy, Scikit-learn

## 📂 Project Structure
```
Gas-and-Oil-Exploration/
|-- Img #Image or Screenshort
|-- Scripts 
  │-- dataset/ # Datasets (seismic & exploration)
  │-- Training models/ # ML models for dev
  │-- custom_model # The Model train on Custom Dataset
  │-- train_mode # the Model train on Default Dataset
  │-- backend_code.py # the model code 
  │-- predication.py # Predication logic code of values
  │-- main.py # Validation and Starting point
│-- requirements.txt # Dependencies
│-- README.md # Project documentation
```

## ⚡ Installation
1. Clone the repository:
  ```
  git clone <-- URL -->

  ```
2. Create and activate a virtual environment:
```
python -m venv venv
source venv/bin/activate   # On Linux/Mac
venv\Scripts\activate      # On Windows

```
3.Install dependencies:Install dependencies:
```
pip install -r requirements.txt
```
4. Run the Tkinter GUI:
```
cd Scripts
python main.py
```
